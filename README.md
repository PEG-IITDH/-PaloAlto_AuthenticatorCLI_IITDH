# Palo Alto Firewall Authentication CLI

## What is Palo Alto Firewall authentication for internet access?

Palo Alto Firewall authentication is the process of verifying a user's identity before allowing internet access on a network.

## Why use a command-line interface?

The default authentication process requires a full web browser, which may not be suitable for lightweight IoT devices.

## How does this solution work?

This solution uses a command-line interface to emulate the HTTP transactions needed to complete authentication. A valid username and password are still required; a full-featured browser is not.
